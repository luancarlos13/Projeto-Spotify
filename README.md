## 🎧 Projeto Spotify 

Este projeto é uma interface inspirada no Spotify, desenvolvida com foco em layout moderno, responsividade e experiência do usuário. A aplicação simula elementos visuais da plataforma original, como navegação lateral, barra de busca e exibição dinâmica de artistas e álbuns.

## 🚀 Funcionalidades

- 🎵 Exibição de artistas populares e álbuns populares
- 🔍 Barra de pesquisa estilizada
- 📚 Seção de biblioteca simulada
- 🎧 Cards interativos com efeito hover
- 📢 Banner promocional fixo (estilo Spotify Premium)
- 📱 Layout totalmente responsivo (mobile, tablet e desktop)
- ⚡ Integração com JavaScript para renderização dinâmica de conteúdo

## 🧱 Tecnologias Utilizadas

- HTML5 🟧
- CSS3 🟦
- JavaScript 🟨
- Font Awesome 🔮

## 🎨 Layout e Design

O design foi inspirado na interface do Spotify, com:

- Tema escuro predominante
- Componentes organizados em sidebar + conteúdo principal
- Uso de grid responsivo para exibição dos cards
- Elementos modernos como bordas arredondadas, sombras e transições suaves

## 📱 Responsividade

O projeto foi otimizado para diferentes tamanhos de tela:

- 💻 Desktop 
- 📲 Tablet 
- 📱 Mobile 

## 🎯 Objetivo do Projeto

Este projeto foi desenvolvido com o objetivo de:

- Praticar HTML, CSS e JavaScript
- Aprimorar conceitos de responsividade
- Reproduzir interfaces reais (UI Clone)
- Criar um projeto visual forte para portfólio


## ⚠️ Aviso

Este projeto possui finalidade exclusivamente educacional e de portfólio. A marca Spotify, seus logotipos, produtos e demais elementos visuais pertencem à empresa Spotify e seus respectivos proprietários.

Este projeto foi desenvolvido apenas para fins de estudo e demonstração de habilidades em HTML, CSS e JavaScript, não possuindo qualquer vínculo oficial, patrocínio ou afiliação com a Spotify.
